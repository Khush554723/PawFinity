# 🌐 Demo Project Website

This repository contains a demo website built as part of my personal project portfolio. The website is developed using **HTML**, **CSS**, **JavaScript**, and the **Bootstrap** framework to create a responsive and interactive user experience.

## 📌 About the Project

This website demonstrates my front-end development skills by combining modern design with real-time API integration. It features a clean, responsive interface and allows users to browse dog images while submitting adoption-related queries. The project is designed with scalability in mind, making it easy to add new features in the future.

### ✨ Key Highlights

* Fully responsive layout using Bootstrap
* Semantic HTML structure
* Clean and organized CSS with reusable components
* Interactive functionality using JavaScript
* Integration with the **Dog CEO API** to display thousands of dog images
* Adoption enquiry form where users can submit queries about the dogs they are interested in
* Modular project structure for easy maintenance and scalability

## 🛠️ Technologies Used

* **HTML5** – Structure and semantic markup
* **CSS3** – Styling and responsive design
* **JavaScript (ES6)** – Dynamic functionality and API integration
* **Bootstrap 5** – Responsive UI components and layout
* **Dog CEO API** – Fetches and displays a large collection of dog images for users to explore

## 🚀 Features

* Browse thousands of dog images fetched from the Dog CEO API.
* Responsive design that works seamlessly across desktop, tablet, and mobile devices.
* Interactive user interface built with JavaScript and Bootstrap.
* Adoption enquiry form allowing users to submit queries about the dogs they wish to adopt.
* Clean and user-friendly navigation with a modern layout.
